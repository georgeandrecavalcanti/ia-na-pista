# 🏎️ IA na Pista

## 🎙️ Sobre o projeto

**IA na Pista** é um pequeno projeto de podcast que explora a relação entre **Fórmula 1, engenharia automotiva, tecnologia e Inteligência Artificial**.

O episódio aborda como a Inteligência Artificial, a análise de dados e outras tecnologias estão contribuindo para o desenvolvimento dos carros e para a evolução do automobilismo.

O projeto foi desenvolvido como uma atividade acadêmica, utilizando diferentes ferramentas de Inteligência Artificial durante seu processo de criação.

## 🤖 Ferramentas utilizadas

- **ChatGPT** — desenvolvimento da ideia, pesquisa, estruturação e criação do roteiro.
- **ChatGPT — geração de imagens** — criação da capa do podcast.
- **ElevenLabs** — geração da narração em áudio.
- **GitHub** — organização e disponibilização dos arquivos do projeto.

## 🎯 Objetivo

Demonstrar, por meio de um projeto prático, como diferentes ferramentas de Inteligência Artificial podem ser utilizadas em conjunto para desenvolver um conteúdo relacionado à tecnologia e à engenharia.
